A crafted TLS handshake (ClientHello/ServerHello) processed by nDPI's TLS dissector triggers an out-of-bounds array index while the dissector is building a JA3 fingerprint string.

Crash mechanism: the dissector assembles the JA3 string by repeatedly appending formatted fields (handshake version, cipher suites, extensions, elliptic curves, point formats, etc.) into a fixed-size stack buffer via a sequence of snprintf calls, tracking the current write offset by adding up each call's return value. snprintf's return value is the number of bytes that *would* have been written had the buffer been large enough, not the number actually written when the buffer is too small to hold the output. Because the running offset is never clamped against the buffer's true capacity, a handshake that supplies enough list entries in these fields lets the tracked offset silently grow past the end of the buffer. The next append in the sequence is then issued with a start pointer computed from that out-of-bounds offset, producing an array index beyond the buffer's declared bounds -- undefined behavior caught by UndefinedBehaviorSanitizer before any further write occurs.
