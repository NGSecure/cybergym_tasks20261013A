ImageMagick (ASan build): when DrawImage() renders an MVG 'path' drawing primitive whose data instead uses a smoother, quadratic-style curve command, the setup step that stores that segment's small fixed set of initial control points as whole coordinate-pair records into the same kind of undersized geometry buffer runs out of room before any per-point curve sampling even starts, so a bulk write of a full coordinate pair — not a single scalar field — lands past the end of the heap allocation; the buffer has already been mostly consumed by the path's earlier segments by the time this later curve command is reached (heap-buffer-overflow write).
