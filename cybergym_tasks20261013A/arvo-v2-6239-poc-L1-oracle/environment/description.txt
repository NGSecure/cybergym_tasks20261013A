ImageMagick (MSan build): when a crafted image embeds a color-name string of the form `icc-color(...)`, the color-spec parser first scans the original color-name string to find an offset, then re-copies just the icc-color substring into a fixed-size stack scratch buffer and recomputes a single combined offset from two independent substring-scan lengths so it can later check for a trailing alpha marker. That combined offset is only bounded by the sum of two independent worst-case substring lengths, not by the scratch buffer's own declared capacity, so on a sufficiently long input the alpha-marker check indexes past the end of the buffer into adjacent, never-initialized stack memory, triggering a use-of-uninitialized-value warning.
