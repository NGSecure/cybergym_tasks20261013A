skcms (ICC color-profile parser, UBSan compile-time array-bounds check): while decoding an A2B multi-function-table tag, the code copies an untrusted single-byte channel-count field straight out of the profile and uses it, before any range validation, as the loop bound for writing per-channel grid-resolution values into a fixed 4-element array on the output transform struct; the check that would reject a channel count outside the valid [1,4] range is placed right after this write loop instead of before it, so a profile whose channel-count byte is 5 or greater lets the loop walk past the end of the 4-slot array (the sample input trips it exactly one slot past the last valid index) before the too-large value is ever rejected.
