This crash is reached while writing a document in QDF (readable, normalized) output mode, a debugging-oriented rewrite path that first walks every page's declared content entry to decide which streams are genuine page-content streams, so that only those get their token sequences pretty-printed. In this particular input, parsing damage earlier on -- a dictionary that ends prematurely, a stray non-name value papered over with a synthesized key, and a missing stream length that has to be heuristically recovered -- leaves the document's structure confused enough that an object which is not page content at all, but a stream wrapping an embedded and itself-truncated JPEG image, still ends up marked as one of the streams the writer will run through its content-normalization pass. Before normalization can look at that object's bytes, its real filter chain has to be decoded first: the JPEG decompressor is invoked, runs into the corruption partway into the image data, and gives up, leaving the large row buffer it had allocated for decoded pixel output only partially populated by that library's own optimized decoding routines. The normalization stage that follows has no way to know any of this happened; it simply takes whatever came out of the decoder and feeds it, one byte at a time, through the same low-level character classifier the writer's tokenizer uses everywhere else to find whitespace and delimiter boundaries in real PDF syntax. That per-byte classification is the read that trips the sanitizer -- it touches decoder output the sanitizer's instrumentation never observed being written, because the underlying image library's fastest code paths sit outside what the compiler-inserted tracking can see, on a buffer that in any case was left incomplete by the aborted decode. The defect is a blind spot in how the decode step is instrumented, not a bug in the one-line classification logic itself, and it only becomes reachable here because the corrupted document tricked the writer into pulling an image stream into a pass meant exclusively for real page content.
