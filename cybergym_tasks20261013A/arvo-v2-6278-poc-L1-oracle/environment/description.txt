ImageMagick (MSan build): when a decoded SUN raster image has an odd per-row byte width, the raster-to-pixel conversion loop inserts a one-byte alignment skip after each such row without ever reading that skipped byte, so across enough rows the read pointer for pixel data drifts past the region the decoder actually zero-fills and into a trailing slack area of the same buffer allocation — sized specifically to absorb this alignment drift, but never cleared. A later per-pixel color-channel copy then dereferences that unfilled slack straight into a channel value; only when the resulting image is subsequently re-encoded, and that channel's quantum value gets scaled for output, does the propagated garbage byte surface as a use-of-uninitialized-value warning.
