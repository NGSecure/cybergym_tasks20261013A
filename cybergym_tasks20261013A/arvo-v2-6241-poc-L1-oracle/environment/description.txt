ImageMagick (MemorySanitizer build): decoding a crafted PCX image's run-length-encoded scanline data fills a per-row pixel buffer that is heap-allocated but never zero-initialized before use, so when the encoded run data for a row is short or malformed and does not fully populate that buffer, the decoder still copies whatever leftover, uninitialized heap bytes remain in it into the image's pixel channel values; that taint then survives inside the image's in-memory pixel representation and only trips MemorySanitizer later, when a subsequent re-encode/write step reads one of those channel values to rescale it down to a narrower per-pixel quantum depth, exposing the still-uninitialized byte as a use-of-uninitialized-value.
