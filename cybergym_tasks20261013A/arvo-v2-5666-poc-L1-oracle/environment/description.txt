MuPDF (PDF interpreter, MSan build): rendering a page whose content stream applies a soft-mask graphics operator assigns the library's shared default grayscale colorspace singleton into the mask's state without taking an extra reference on it, so a later, normal release of that state over-decrements the singleton's reference count and it gets torn down prematurely; the library's own object-cache reclaim logic then reads through that already-invalidated shared object during shutdown, producing a use-of-uninitialized-value warning.
