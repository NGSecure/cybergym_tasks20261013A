ImageMagick (MSan build): the PCX decoder reads the file's embedded color palette into a fixed 256-entry stack buffer sized against an initial default palette-size guess, then afterward recomputes a possibly larger palette size from the image's bit-depth/plane-count header fields and copies that many entries back out of the same buffer — so any entries beyond what the initial guess actually filled from the file are leftover, uninitialized stack bytes; those uninitialized RGB values get copied into the image's color table and propagated into every decoded pixel, and a later black-and-white-detection check (run while re-encoding the image) reads them, triggering a use-of-uninitialized-value warning.
