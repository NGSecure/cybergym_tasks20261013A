ImageMagick (image conversion library, ASan build): writing a portrait-orientation image out through the PCD (Kodak Photo CD) writer first produces a rotated working copy of the image to actually drive the encode, but in the vulnerable path that working copy keeps its own, independently-owned output-buffer object instead of sharing the one the top-level in-memory blob-write helper had already set up for the original image — so every header and tile byte the writer emits accumulates only inside the rotated copy's private buffer. When the writer finishes and discards that temporary rotated image, tearing it down also releases the buffer holding the just-written output, while the original image's own output-buffer object was never touched and still carries a stale, unrelated value. The top-level blob-write helper then reads that stale value back out of the original image's buffer object and hands it to the generic memory-release routine, which aborts because the address was never something the allocator actually returned.
