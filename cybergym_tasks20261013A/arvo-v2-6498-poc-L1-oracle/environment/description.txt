ImageMagick (MSan build): reading a crafted MIFF-family image header parses one of the header's numeric fields with the generic geometry-string parser into a local, multi-component structure that was never explicitly zeroed before the header-parsing loop began. That generic parser only fills in the components whose corresponding flag it detects in the input string, so a header value that supplies fewer components than the struct holds leaves the remaining components as leftover stack garbage. The partially-filled structure is then copied straight into a persistent image property, so the uninitialized components survive read time and are only read back out later, when the same (now in-memory) image is re-encoded — that later read is what MemorySanitizer flags as a use-of-uninitialized-value. The same missing pre-zero step is duplicated in a second, closely related coder for a sibling on-disk cache format that shares essentially the same header-decoding structure, so both were fixed together.
