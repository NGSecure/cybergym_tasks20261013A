Skia's skottie module (Lottie/Bodymovin animation renderer, MSan build): building a camera layer's 3D view transform constructs a look-at basis matrix and inverts it in place, but the code that consumes the inversion result discards the boolean success/failure returned by the invert routine instead of checking it. When the requested camera geometry makes that basis matrix singular (non-invertible), the inversion helper leaves its output matrix untouched on the failure path rather than falling back to a defined value, so the matrix keeps whatever indeterminate bytes it had at allocation time. That partially-uninitialized 4x4 matrix is then folded into the layer's cumulative transform through further matrix multiplication (implemented with SIMD vector add/multiply helpers) and propagated into the scene-graph transform node that applies it, and MemorySanitizer flags the eventual read of the still-uninitialized floats as a use-of-uninitialized-value warning.
