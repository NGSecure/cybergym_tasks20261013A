ImageMagick (MSan build): when a new image object is created, a local extract/crop rectangle is declared on the stack without being zero-initialized, then handed to a geometry-string parser that only fills in the fields whose components were actually present in the (often absent) geometry string, leaving the remaining fields as leftover stack garbage. That partially-filled rectangle becomes part of the newly created image's persistent state, and while resolving an embedded "%..." property escape inside a corrupted LABEL-format label string, the interpreter computes the image's content signature and allocates/copies a string sized from those still-uninitialized fields — surfacing as a use-of-uninitialized-value warning far downstream of where the garbage was actually created.
