file/libmagic's DER parser (UBSan build) renders a decoded ASN.1 tag number into a human-readable name by looking it up in a fixed table of tag-name strings, using a bounds check based on the highest tag value the format defines. That table is missing one entry partway through the range, so every name after the gap is shifted down by one slot and the table ends up with one fewer usable slot than the bound the check allows. Feeding the tag-name lookup the single highest legal tag value therefore passes the bounds check but indexes one slot past the end of the table, an out-of-bounds array read that UBSan flags.
