ImageMagick (MVG vector-graphics drawing engine, ASan build): rendering a `path` primitive from a crafted MVG (Magick Vector Graphics) script allocates its point-storage buffer from a fixed per-primitive point budget that implicitly assumes command parsing stops as soon as a coordinate token in the path data fails to parse as a number. In reality, the loop walking the path's command letters performs no such check at all when a coordinate token fails to parse -- there is no failure flag or early-exit path of any kind -- so it simply carries on, continuing to turn the remaining command letters -- including curve commands that each expand into many intermediate points -- into further points appended to that buffer. A crafted path string that packs extra curve segments in after the first bad coordinate can therefore push the running point count past the buffer's fixed capacity, and the low-level routine that appends the next point during a curve-segment emission pass ends up writing 8 bytes past the end of the under-sized heap allocation.
